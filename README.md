# 片段助手

**v1.1.0 · Windows 64 位桌面工具**

手动标记视频中要保留的一个或多个片段，预览处理结果后导出新文件或确认替换原片。视频仅在本机处理，不会上传。

[English](README.en.md) · [完整使用说明](使用说明.md) · [User Guide](User%20Guide.md)

## 下载与启动

在 [GitHub Releases](https://github.com/kylefu8/clip-helper/releases) 下载 `clip-helper-v1.1.0-windows-x64.zip`，完整解压后双击 `片段助手.exe`。请保留旁边的 `_internal` 文件夹；无需安装 Python。建议使用 Windows 10/11 64 位。

## 界面语言

使用界面中的语言选择框即时切换简体中文或 English，选择会被记住。新安装首次运行时跟随系统语言：中文系统默认中文，其他系统默认 English。切换语言不会重新载入当前视频或已标记片段，也不改变文件名或标记存储位置。处理进行中暂不可切换。

## 快速使用

1. 选择视频目录，在左侧选择视频。
2. 播放或拖动时间轴，用 **I** 标记开始、**O** 标记结束。
3. 点击**添加保留片段**，将区间加入列表。每段都要添加；一个视频可以保留多段。
4. 点击**准备已标记的视频**，等待处理和校验完成。
5. 回看结果，再选择导出新文件或确认替换原片。

软件不重新压缩画面。每段开始会向前对齐到关键帧，可能多保留一点开头；多段按时间顺序拼接，实际范围会显示在结果中。

**确认替换会永久移除未保留的画面，成功后不留原片副本。** 要保留原片时请选择导出新文件。
